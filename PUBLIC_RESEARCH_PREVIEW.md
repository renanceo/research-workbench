# Public Research Preview

> **Research preview — not a validated paper-positioning service. Real-manuscript diagnostics and paid use remain unavailable until Gate 1 is completed.**

This repository publicly demonstrates the software contracts, safety boundary,
and intended report shape of a research workbench for paper-positioning
decisions. It does not expose or implement the private judgment system.

## What the synthetic demo shows

The CLI demo uses only visibly fictional JSON fixtures and performs no network
request or model call. It shows this product shape:

```text
synthetic manuscript reference
→ structured intake contract
→ synthetic strategy selection
→ mock diagnostic execution
→ community, candidate, false-friend, and abstention report
→ synthetic official-fact provenance record
→ full public output-contract validation
```

Run it after installing the project dependencies:

```bash
python scripts/run_public_preview.py
```

Every value printed by this command is synthetic and illustrative. Contract
authorization and metering fields are demonstrated as data shapes only; the
preview performs no charge and offers no paid use.

## What remains unavailable

The preview does not accept uploads or pasted manuscripts. It has no account,
waitlist, payment, email-marketing, contributor-database, or user-data system.
It must not be described as finding the best journal, improving acceptance, or
achieving an accuracy score.

The following remain private and are not part of this repository:

- paper-positioning and review-defense protocols;
- production prompts and orchestration;
- venue and community profiles;
- thresholds, scoring rules, and calibration records;
- benchmark cases, permissions, judge answers, and commitments; and
- real user manuscripts or model outputs derived from them.

Any future research contribution by a user requires a separate, optional,
specific consent. Uploading a manuscript must never automatically make it
training, calibration, or evaluation data.
